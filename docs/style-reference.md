## Corrected example
- 「なに会ってんだよ」 first drafted as "What are you meeting?" (会 read literally). The font writes 言 as 会: it is
  "What are you talking about?" (glossary Style rules).

## Rules of thumb
- One utterance per box sequence: translate the whole unit, then break pages (` // `) at sentence or clause ends.
- Ellipses: `...`; a line that is only dots becomes `......` (or `... ...` for two lines of dots).
- Cries: うわあっ -> "Whoaaa!", ジンー！！ -> "Jiiin!!", ググ -> "Ngh...", グワアー -> "Graaah!".
- Kid-friendly: クソ -> "Damn" at most; no stronger swearing.
